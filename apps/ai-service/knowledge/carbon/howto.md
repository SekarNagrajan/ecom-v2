# Carbon calculator how-to

## Prerequisites
- Carbon calculator access (public or authenticated depending on tenant).
- Lane and container count.

## Estimate emissions
1. Open [[cite:/app/carbon|Carbon Calculator]].
2. Enter origin, destination and containers.
3. Review the estimate and leg breakdown when shown.
4. Optionally start from a sailing on [[cite:/app/schedules|Schedules]] when that action exists.

## Expected outcome
An indicative CO₂ estimate for the lane — not a certified inventory report unless your tenant says otherwise.

## Assistant usage
Ask for a carbon estimate for a lane; the assistant can call the estimate tool when available.
