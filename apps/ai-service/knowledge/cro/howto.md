# Container Release Order (CRO) how-to

## Prerequisites
- Booking eligible for empty release.
- CRO module access.

## Request or view CRO
1. Open [[cite:/app/cro|CRO]].
2. Search by booking or related reference.
3. Review eligibility messages and release details.
4. Complete any on-screen actions your tenant requires.

## Expected outcome
A CRO that authorises empty container pickup when checks pass.

## Tips
- If eligibility fails, resolve the listed booking/payment/document issues first.
- Pickup depot details come from the CRO record, not from chat guesses.

## Assistant usage
Ask why a CRO might be blocked or how to open CRO. Live eligibility always follows the portal CRO screen.
