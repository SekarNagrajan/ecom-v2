# Delivery Order (DO) how-to

## Prerequisites
- Import / destination workflow in progress.
- Delivery Order module access.

## Find a delivery order
1. Open [[cite:/app/delivery-order|Delivery Order]].
2. Search by B/L, container or the references your tenant supports.
3. Review release / delivery status on screen.

## Expected outcome
DO details for cargo release at destination when available.

## Assistant usage
Ask what a DO is or how to open the screen. The assistant will not invent DO numbers.
