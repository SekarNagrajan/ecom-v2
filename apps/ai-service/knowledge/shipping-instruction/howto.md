# Shipping Instruction (SI) how-to

## Prerequisites
- Booking access and a confirmed / eligible booking for SI.
- SI (Shipping Instruction) module access.

## Create or complete an SI
1. Open [[cite:/app/shipping-instruction|Shipping Instruction]].
2. Find the booking or start a new SI from the eligible booking.
3. Complete parties, cargo lines and any required references.
4. Review and submit on the SI screen.

## Expected outcome
An SI record linked to the booking, ready for B/L processing according to your workflow.

## Common checks
- Party roles (shipper, consignee, notify) must match business rules.
- Cargo totals should align with booking equipment.
- Submit only after preview validation passes.

## Assistant usage
Ask how to complete an SI or what a field means. The assistant explains steps from the guide and can navigate to SI; it does not submit the SI for you.
