# Tracking how-to

## Prerequisites
- A container number, B/L number or booking reference.

## Track a shipment
1. Open [[cite:/app/tracking|Tracking]].
2. Choose search type: Container, B/L or Booking.
3. Enter the reference and search.
4. Review progress, latest activity and container status.

## Expected outcome
Tracking details show vessel/voyage when available, progress and per-container events.

## Tips
- Use the exact reference format shown on documents (no extra spaces).
- If nothing is found, verify the search type matches the reference kind.
- Live map or share features appear only when enabled for your tenant.

## Assistant usage
Ask the assistant to track a container/booking/B/L; it uses the same portal tracking lookup and will not invent statuses.
